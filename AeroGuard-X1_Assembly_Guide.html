Read before power-on

  • SIM800L needs its own ~4V high-current supply — never the Uno 5V pin.
  • Level-shift Uno TX → SIM800L RX with a voltage divider (10k + 20k).
  • The ESP32 is required. Its signal pins are 3.3V. Uno A3 is 5V — use a 10k + 20k divider into ESP32 GPIO16. A straight 5V wire can kill the ESP32.
  • ESP32 GPIO17 can go straight to Uno A1 (3.3V is safe for the Uno). Tie every ground together, including the ESP32.
  • Use a data USB cable (not charge-only) when you put the program on the ESP32. Hold BOOT if upload sits on “Connecting…”.
  • Common ground for every module including battery and SIM.
  • Set real phone numbers in firmware before any call/SMS demo. Set WiFi name and password in the ESP32 sketch (or use the AeroGuard-X1 fallback hotspot).

Build

Steps

01 — Power rails

5V · GND · separate 4V

Breadboard 5V/GND from Uno. Keep SIM800L on a separate regulated ~4V rail with shared ground only.

02 — Gas sensor

A0 · 5V · GND

One MQ sensor for kitchen/cylinder area. Warm-up a few minutes on first power is normal.

03 — Flame sensor

A2

Analog out to A2. Test briefly with a lighter (no gas nearby) and note Serial readings.

04 — LCD

A4 SDA · A5 SCL

If blank, I2C-scan and set address in code (0x27 or 0x3F).

05 — Status LEDs

D2 green · D3 yellow · D4 red

Anode via 220Ω to pin, cathode to GND. Green = LOW, yellow = MEDIUM, red = CRITICAL/FIRE.

06 — Buzzer

D8

Positive to D8, negative to GND.

07 — Buttons

D7 reset · D9 demo

Each button: one leg to pin, other to GND (internal pull-ups). Label the lid: RESET and DEMO.

08 — SD module

D10–D13

Local incident history for demos and landlords — not marketed as fire-proof storage.

09 — SIM800L

4V · D5 · D6

TX→D5, RX←D6 via divider. Active SIM with credit. Slow blink ≈ registered.

Demo: CRITICAL/FIRE will place a real call — warn the owner phone holder.

10 — ESP32: what it is (required)

Uno = farm · ESP32 = water channel to the phone

The Uno watches gas, lights, buzzer, SIM, and the SD log. It cannot join WiFi. The ESP32 is the channel: it copies the Uno’s STATUS line onto WiFi so a phone browser can open /status, and it can send APP_CMD:VENT_OPEN back when you tap open-vents. Wire it, flash it, and test it. Do not leave it unwired.

11 — ESP32 wiring + 5V→3.3V divider

GPIO16 RX2 · GPIO17 TX2 · common GND · 10k + 20k

Three signal paths. The Uno’s A3 pin is 5V; the ESP32 GPIO16 pin can only take about 3.3V. Knock it down with two resistors.

FromToHow
Uno A3ESP32 GPIO16 (RX2)10k from A3 to the junction; 20k from that junction to GND; jumper from the junction to GPIO16
ESP32 GPIO17 (TX2)Uno A1Straight wire — no divider

3.3V: never run Uno A3 straight into GPIO16. If you swap the resistors (20k on top, 10k to ground) the signal may be too weak (~1.7V). USB power on the ESP32 is fine for the demo.

12 — Flash the ESP32

Arduino IDE · ESP32 Dev Module · Serial 115200 · data USB cable

Put esp32_aeroguard_bridge.ino on the ESP32. The Uno still gets aeroguard_x1-1.ino at Serial 9600 — switch board and port each time.

  1. File → Preferences → Additional boards manager URLs → paste https://espressif.github.io/arduino-esp32/package_esp32_index.json
  2. Tools → Board → Boards Manager → search esp32 → install esp32 by Espressif.
  3. Tools → Board → ESP32 Dev Module. Pick the ESP32’s USB port.
  4. In the sketch, set WIFI_SSID and WIFI_PASS to your 2.4 GHz WiFi (keep the quotes). Leave the placeholders if you will use the fallback hotspot.
  5. Use a data USB cable. Click Upload. If it sits on Connecting..., hold the BOOT button, then release when writing starts.
  6. Open Serial Monitor at 115200, tap EN/RESET, and write down the IP (Remote URL: http://…).

13 — Phone test + fallback hotspot

Browser /status · /vent/open · SSID AeroGuard-X1

The companion app can still pretend it found a device. Hardware proof is the phone browser on the same WiFi. Use http, not https.

  • http://<ip>/status — JSON with level / demo / gas. The raw line looks like STATUS level=SAFE demo=0 gas=0 vent=APP once the Uno is talking.
  • http://<ip>/vent/open — should return ok and send APP_CMD:VENT_OPEN to the Uno.
  • If home WiFi is not set (or will not join), the ESP32 opens its own network: name AeroGuard-X1, password aeroguard. On the phone join that network, then open http://192.168.4.1/status.
Case: the printed shell has an ESP32 shelf about 51 × 28 mm. Seat USB and antenna toward the opening. Then press DEMO: LOW → MEDIUM → CRITICAL → FIRE. RESET clears and recalibrates. Uno Serial 9600 · ESP32 Serial 115200.

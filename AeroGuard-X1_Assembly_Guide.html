Read before power-on

  • SIM800L needs its own ~4V high-current supply — never the Uno 5V pin.
  • Level-shift Uno TX → SIM800L RX with a voltage divider.
  • Common ground for every module including battery and SIM.

Build

Steps

01 — Power rails

5V · GND · separate 4V

Breadboard 5V/GND from Uno. Keep SIM800L on a separate regulated ~4V rail with shared ground only.

02 — Gas sensor

A0 · 5V · GND

One MQ sensor for kitchen/cylinder area. Warm-up a few minutes on first power is normal.

03 — Flame sensor

A2

Analog out to A2. Test briefly with a lighter (no gas nearby) and note Serial readings.

04 — LCD

A4 SDA · A5 SCL

If blank, I2C-scan and set address in code (0x27 or 0x3F).

05 — Status LEDs

D2 green · D3 yellow · D4 red

Anode via 220Ω to pin, cathode to GND. Green = LOW, yellow = MEDIUM, red = CRITICAL/FIRE.

06 — Buzzer

D8

Positive to D8, negative to GND.

07 — Buttons

D7 reset · D9 demo

Each button: one leg to pin, other to GND (internal pull-ups). Label the lid: RESET and DEMO.

08 — SD module

D10–D13

Local incident history for demos and landlords — not marketed as fire-proof storage.

09 — SIM800L

4V · D5 · D6

TX→D5, RX←D6 via divider. Active SIM with credit. Slow blink ≈ registered.

Demo: CRITICAL/FIRE will place a real call — warn the owner phone holder.

10 — ESP32 WiFi (app / remote)

A1 / A3 · ESP32 DevKit

Wire ESP32 UART2 (GPIO16 RX / GPIO17 TX) to Uno A3/A1 with a level shift into the ESP32 RX. Flash esp32_aeroguard_bridge.ino, set WiFi, then open /status on the phone. Firmware already mirrors STATUS / APP_CMD:VENT_OPEN to this link.

11 — Case + verify

Print · upload · Serial 9600

Print the v2 compact case (126×90×36 mm) from aeroguard_x1_case.scad — rounded shell with AeroGuard engraved on the lid/front and mounts for Uno, ESP32, SIM, SD, and 4V buck. Upload sketches. Press DEMO: LOW → MEDIUM → CRITICAL → FIRE. RESET clears and recalibrates.
